# Authverse

![Authverse Logo](./app/web/public/logo.png)

**Authverse** waa CLI casri ah, fudud, isla markaana developer-friendly ah oo kaa caawinaya inaad **hal command ku samaysato authentication system dhamaystiran**.

Waxay kuu diyaarinaysaa authentication screens, database configuration oo leh **Prisma ama Drizzle**, **Better Auth integration**, OAuth providers, iyo authentication flows ammaan ah — dhammaantood si toos ah loogu sameeyo project-kaaga.

Authverse waxaa loogu talagalay developers doonaya **authentication degdeg ah, nadiif ah, oo professional ah**, iyaga oo aan waqti badan ku lumin configuration-ka gacanta.

---

## Authverse Waa Maxay?

Authverse waa CLI tool kuu samaynaya authentication system dhamaystiran oo loogu talagalay **Next.js** iyo **TanStack Start** projects.

Waxay si otomaatig ah ugu dhex daraysaa:

* **Better Auth** — Authentication framework casri ah
* **Shadcn/ui** — Authentication screens diyaar ah
* **Prisma ama Drizzle** — Database integration
* **OAuth Providers** — Google iyo GitHub authentication
* **API Routes** — Authentication endpoints diyaar ah
* **Environment Variables** — Configuration otomaatig ah
* **TypeScript** — Taageero buuxda oo TypeScript ah
* **Secure Authentication Flows** — Qaab authentication oo ammaan ah

Halkii aad gacanta uga samayn lahayd packages badan, API routes, database configuration, iyo authentication screens, **Authverse ayaa dhammaan kuu diyaarinaysa**.

Hal command kadib waxaad heli doontaa:

* Frontend iyo backend authentication dhamaystiran
* Authentication UI diyaar ah
* Email/password authentication
* Google iyo GitHub OAuth
* Database integration
* Security configuration
* Project structure nadiif ah oo developer-friendly ah

## Quick Start

Isticmaal command-kan si aad Authverse ugu bilowdo project-kaaga:

```bash
npx authverse@latest init
```

Authverse waxay ku siinaysaa talaabooyin aad ku dooranayso:

* UI framework-kaaga
* Database-kaaga — Prisma ama Drizzle
* Haddii aad rabto authentication UI screens
* Authentication providers-ka aad rabto

Kadib Authverse waxay si otomaatig ah u samaynaysaa files-ka, configuration-ka, authentication screens-ka, iyo database setup-ka loo baahan yahay.

Markaad CLI-ga isticmaasho, project-kaagu wuxuu diyaar u noqonayaa:

* **Better Auth**
* **Shadcn/ui**
* **Database integration**
* **Authentication routes**
* **OAuth providers**
